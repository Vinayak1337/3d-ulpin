## Decision

Vinayak owns complex core engineering and architecture. A owns data research/acquisition, small fixture packs, bounded input inspectors/adapters and data tests. B owns input/storage APIs using Vinayak’s helpers, ordinary web/mobile screens and workflow/device tests. Both own the code they are assigned; this is not a plan to make them only researchers or testers.

The original 03 and the staffing prose in 02 assumed specialist backend owners and restricted Vinayak to client work. That allocation is deliberately superseded here by the user’s latest description of the team. The original product, nine modules, six phases and technical stack remain the baseline. Reference copies are retained unchanged; their older ownership statements do not override this revised plan.

## Start

A starts A01–A03. B starts B01–B02. Vinayak starts V00 and releases V01 templates/helpers incrementally. Live A04/B03 integration waits for only its required helper/contract, not for the whole app. Each teammate keeps one primary implementation packet active.
