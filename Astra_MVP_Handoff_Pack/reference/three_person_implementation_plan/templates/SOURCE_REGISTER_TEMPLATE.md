## Acquisition status

Use a precise description: lead only; access requested; acquired; inspected; suitable for a named purpose; unsuitable/blocked. A downloadable listing is not an acquired file. Record actual filenames/sample hash and inspection result once available.

## Permission status

Record exact intended use (development, demonstration, publication, other), provider terms/authorization evidence, conditions and unresolved questions. Unknown or pending is not approved. Synthetic data is explicitly synthetic, with its generation/provenance noted; it is not synthetic government evidence.

## Selection decision

For each core input choose a practical primary route and fallback. Explain why optional leads are deferred. Keep file acquisition separate from the processing that would make it useful. Do not assume that imagery, labels or clouds from a nearby city describe the coherent case.
