# Indian pilot source access — 15 September 2026

The Indian coherent-block acceptance gate is **not met**. No authorized Indian feature subset or matched building plan/section package was acquired. The existing Bronx data and synthetic engineering fixtures do not satisfy that gate.

This was a bounded inspection of three serious official candidates. [research/manifest.json](research/manifest.json) records the exact URLs, retrieval dates, response sizes and SHA-256 hashes. [research/probe-results.json](research/probe-results.json) records each actual spatial request and count. Restricted source documents/geometries are not bundled here. The files in this directory are our access observations, not survey evidence.

GMDA's parcel schema advertises owner names, Aadhaar and mobile fields. None of those values, geometries or remarks were requested. No `outFields=*` request was used. The service's host and overall extent do not prove locality, semantic correctness or municipal responsibility. Nine zero counts apply only to the exact recorded envelopes; they do not imply the whole service is empty.

The live GMDA catalog entry remains disabled for feature acquisition. We did not send any permission email, bypass a login, fabricate Indian source files, infer floor heights or recast a foreign fixture as Indian acceptance.

To complete acquisition, the data holder must identify one locality and authorize a bounded cache/process/display/redistribution of full intersecting buildings, parcels or public boundaries, roads and a real utility or utility drawing, plus two matched plan/section packages and a third dossier. The grant must cover derivative use and any external AI processing. The supplied package needs stable IDs, document revisions, a horizontal CRS and named vertical reference, source field meanings, and personal-data exclusions. These are precise external inputs; native ingestion, mapping, review and preparation remain usable meanwhile.
