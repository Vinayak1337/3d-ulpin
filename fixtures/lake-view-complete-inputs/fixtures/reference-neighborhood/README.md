# Lake View demonstration neighborhood

All geometry, plans, names and display assets are authored fictional inputs. No survey, statutory, ownership, observed-utility or geographic claim. Display placement uses a separate synthetic EPSG:32643 location. Run scripts/reference/generate.py to recreate originals and presentation GLBs; run pnpm demo:seed to import, process, review and persist them. Metrics and findings are computed by the application, not this generator.
