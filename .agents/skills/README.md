# Project design skills

Installed from the catalog linked by [Taste Skill](https://www.tasteskill.dev/), repository `Leonxlnx/taste-skill`, on 2026-09-13 using the Codex skill installer.

- `skills/taste-skill` → `taste-skill`: catalog's design skill; its current scope is landing pages and portfolios, so its marketing-page composition rules are not applied to this registry application.
- `skills/minimalist-skill` → `minimalist-skill`: warm neutrals, restrained accent, clear typography and flat interface hierarchy.
- `skills/redesign-skill` → `redesign-skill`: inspect the existing stack, diagnose usability issues and improve without breaking existing functionality.

The registry combines the relevant minimalist/redesign instructions with the user's installed `frontend-design` skill. It retains native controls, keyboard access, reduced-motion support, local fonts/assets and the existing Cesium/source-preview components.
