# PortalHeader

The Public Portal frame: UX4G accessibility bar on top, then the header with the department-mark slot, wordmark, language switch and sign-in.

- The dashed slot is where the department's own mark goes; never draw a seal or emblem.
- Language switch shows both scripts: **English / हिन्दी**. Text size and contrast controls sit in the accessibility bar.
- Build it from the UX4G Accessibility Bar and Navbar components themed with these tokens.

## Usage

```jsx
<PortalHeader />
```
