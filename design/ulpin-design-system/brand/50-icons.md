# Icons

Phosphor Regular icons (MIT, Phosphor Icons), copied unchanged from the phosphor-icons/core repository. Each is a 256-unit single-ink SVG drawn with `fill="currentColor"`: inline it so it takes the text colour (`ink-soft` in toolbars, `ink-muted` in chips, the status colour in badges). Use the `Icon` component (`<Icon name="warning" />`), which inlines the path so it inherits the text colour.
