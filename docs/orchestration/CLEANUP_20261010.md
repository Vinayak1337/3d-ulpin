## What was checked

- **All 31 worktrees** (the main checkout, 16 Codex desktop worktrees, 11 worker worktrees under `E:/Projects/ulpin-wt`, 3 other folders in `E:/Projects`) and **all 112 local branches**.
- For each one: uncommitted, untracked and ignored files; whether its tip is an ancestor of `staging`; and, for every file it changed, whether that exact file content exists anywhere in `staging`'s history.
