## Auth, errors and scene boundary

[HTTP authority](../../apps/api/src/common/request-context.ts) requires allowed loopback Host/port and same-origin or configured loopback Origin; private guards reject cross-site fetches. [Principal](../../packages/server/src/modules/usp/principal.ts) is server-owned `ULPIN_LOCAL_OPERATOR_SUBJECT`, current access/policy pins and local process attribution, not human login. No caller actor/identity override; absent configuration is `503 LOCAL_OPERATOR_CONFIGURATION`.

Failures use nested `{error:{code,message,requestId,…}}`; evidence adds `retryable`, ordinary errors may add `details`. Preserve `403` denial, `404` absent selected object, `409 STALE_REVISION`/other pin or key conflict, `413 DOCUMENT_SIZE`, `422 INVALID_INPUT`/part/query errors and runtime `503/504`; evidence malformed input can be `400 USP_REQUEST_FAILED`. Original stays retained through failure. Deliberate extraction retry: POST `/ingestion/cases/{caseId}/sources/{sourceId}/documents/retry` with `{requestKey,expectedCaseRevision,expectedSourceRevision,sourceSha256,mode:'native_only'}` → 201 receipt/new job pins.

[Client unwrap](../../packages/api-client/src/index.ts) returns the whole success body; take `.data` only for USP. Send actual multipart File with browser-generated boundary. Preserve `x-ulpin-local-source` distinction. [Scene](../../packages/scene/src/types.ts) consumes canonical IDs/local east–north metres and explicit height states; these source-only claims supply no footprint, transform, building-relative height, storey IDs or extrusion. Unknown CRS/vertical datum/links remain visible; PDF page points are not scene metres or GMDA coordinates.
