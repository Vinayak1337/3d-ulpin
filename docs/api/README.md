## Access and errors

`/api` provides unguarded service information. The v1 catchall and USP routes require loopback URL/Host and a local Origin when supplied; the principal for USP is server-derived `local_demo` operator, not a caller header/body. Saved dataset/core reads use the stricter local Host/origin and cross-site checks in `spatial-core-http.ts`; spatial ML checks local hostname and Origin. The legacy spatial compatibility route itself has no local guard. The calibration route serves only bounded public synthetic assets without a local guard. Deployment must keep the operational app loopback/private. None of these routes is a public sign-in or multiuser authorization API. Do not expose the app or private downloads outside the qualified local boundary.

The legacy catchall returns `{error:{code,message,details?,requestId}}` for application errors and 422 for Zod input. USP returns `{error:{code,message,retryable,requestId}}`; Zod/core-contract failures map to 400, application errors use their own status, unknown failures map to 503. Spatial ML returns `{error:{code,message,requestId}}`; saved datasets and some spatial compatibility endpoints return only `{error:{message}}`. There is no universal error envelope, so handle per operation family. Unknown method/path combinations through the catchall return 404. The AI derivative crop route is an intentional 403 `AI_IMAGE_PRIVACY` denial even though its URL remains recognized.

## Headers, bounds and exact bytes

- `POST /cases/{caseId}/sources` accepts multipart `file`, `profile`, optional `familyId`, and optional `Idempotency-Key`; the route rejects declared `Content-Length` above 17 MiB and instructs a 16 MiB file cap. The same key is forwarded for `demo-inputs`. This is not a durable multipart-large-original contract.
- Area GIS inspection accepts multipart `file` and optional `layer` only; its JSON payload is rejected. Parent `/import-packages` accepts multipart GIS import or a JSON acquisition reference. Package `/documents` requires current `expectedRevision` and 1–100 `entityIds`; `/source-documents` requires a source workspace, uses an empty entity list, and accepts optional UUID `requestKey` for same-payload replay. The regular document route ignores `requestKey`. Missing `expectedRevision` is coerced to zero and normally conflicts. Area multipart intake and supporting-document routes reject declared `Content-Length` above 17 MiB and instruct a 16 MiB file cap. `POST /spatial-datasets` streams at most 20 MiB with `X-File-Name`; `/spatial-datasets/{id}/ml/source` requires an encoded simple PDF/PNG/JPEG `X-File-Name` and UUID `X-Request-Key`. The stream cap is 16 MiB; the retained document service caps PDFs at 10 MiB. Same-key identical source replays and changed bytes/metadata conflict. Dataset ML action is selected by `?action=review`; other values queue. A source name or key alone does not assert official provenance.
- Case build and apply-levels use `expectedRevision`; unit edit, package review/commit, registry draft/review and officer commands have route/service revision checks. USP mutation bodies use `UspMutationGuardSchema` (`requestKey`, expected version/manifest as appropriate). See exact Zod schemas before retrying a write; a random retry may create a second intent.
- `GET /registry` is capped at 100 rows, search `q` is sliced to 150 characters, and there is no cursor. USP `scope/read` uses the contract's cursor/limit; some work queue/search APIs use their own fixed limits. Do not assume all lists paginate alike.
- `GET /sources/{sourceId}/file` reads the stored original object, returns its MIME and inline filename with `nosniff`; this legacy path does not add a source hash header. `GET /spatial-datasets/{id}?original=1` returns original bytes with `X-Source-SHA256`, `Content-Disposition: attachment`, and JSON/ZIP content type. USP `POST /evidence/original` returns authorized original bytes with `X-Source-SHA256` and attachment disposition. `GET /usp/packets/{packetId}` returns a derivative packet, `X-Artifact-SHA256` and format-specific filename. A packet is not an original-source bundle. Registry/investigation exports are generated artifacts. Preserve these distinctions in downloads and caches.
- `GET /spatial/core/areas/{areaId}` accepts only `world` and optional 64-hex `expectedDigest`, returns quoted `ETag` with `readDigest`, and sends 409 on a digest mismatch. `GET /spatial/areas/{areaId}` is the older compatibility projection with explicit world. Neither endpoint proves global placement or ownership.
