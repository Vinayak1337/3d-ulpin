# Attached bulk workflow versus the actual product

Audited 21 September 2026 against the user-supplied Pasted text.txt, current code and T064–T078 evidence. A past milestone is not fresh verification of every workflow. This audit deliberately distinguishes the new import preview from saved service-backed work.

| Requirement | Current implementation / remaining gap |
| --- | --- |
| Batches / Map / Register | Consistent three-section labels; global navigation opens directories. Contextual Open register keeps the selected building and map. Workspaces remain contextual compatibility routes. |
| Bulk file receipt, ask only for missing details | Existing AddFiles retains documents and inspects GIS, detects fields and supports per-file failures. New source ZIP import reads geometry/schedules/controls/rights by declared schema without manual property forms. Complete ZIP is preview-only; not integrated into durable batch intake. |
| One import builds the reference-style neighbourhood | Implemented for the new complete Lake View source ZIP, through original GeoJSON/CSV → canonical adapter → shared MapViewport. No prebuilt normalized.json shortcut. |
| Full supplied format vocabulary | New bundle contains actual PDFs/SVG/GPKG/CSV/LAS/LAZ/GeoTIFF/JPEG/DOCX and observed MASTER/normalized fields. Original hashes are verified. Binary receipt and geometric extraction remain distinct. |
| Auto-association and preserved identity | Source keys, parcel/building/floor/unit joins, floor IDs, residents, parties, rights and document links are validated. Broken right/document/control references reject the draft. General unknown real-world association/deduplication requires reviewed adapter work. |
| Exception-first review | Preview shows the computed count and source-linked findings; map selection locates intersections. Existing saved ImportReview exposes actual findings, questions, coverage and original downloads. Preview findings cannot be falsely marked recorded. |
| Background processing, retry and resume | Existing dispatcher/Celery/preparation cases retain jobs/attempts; local services recovered without resetting volumes. Complete ZIP browser normalization is bounded synchronous preview work, not a durable resumable job. |
| Validate and record exact reviewed scope | Existing GIS/registry review and revision checks are retained. New mixed-source package cannot yet record as a whole. Safe independent-subset recording and atomic connected-object groups are not established by the preview. |
| Right / party / occupant separation | New source CSVs and document-linked assertions demonstrate ownership, floor lease/common use and utility easement separately from residents. All are synthetic and unreviewed. Receipt assertions are not promoted to legally verified core facts. |
| Source originals / revisions / exports | Every package member is fingerprinted. Original source downloads and exact input ZIP work. Canonical candidate export remains inspection-only; history/new revisions use saved service workflows. |
| Any incoming data / all maps | Multiple independent source arrangements and supplied MASTER/normalized fixtures use the shared map/schema. Current detailed profile is bounded, not arbitrary GIS/IFC/CAD/LiDAR/PDF support. Unknown geometry stays unavailable. |
| AI extraction and topology | Existing local ML assistance paths remain. Preview computes qualified polygon intersections; it does not infer ownership or generate actual AI output from the binary sample files. Vertical unknowns stay unknown. |
| Hindi / accessibility / large-area operation | Keyboard search and responsive map tools are checked here. Localization and qualification of broad-area streamed intake are separate unfinished requirements. |

## Next bounded implementation

Connect verified source-package receipts to existing source storage and durable batch identity, with a reviewed named-frame mapping and the existing record/revision boundary. Prove exact original readback, resume/reimport idempotence, source-derived geometry, independently eligible recording scope and stable floor IDs before calling the complete attached workflow finished. Do not create a browser-only “Recorded” badge, overwrite a populated demo or infer a geographic anchor for these local metre sources.
