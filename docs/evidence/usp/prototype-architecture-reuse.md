## One mixed-bundle production pattern

Add a bounded **inventory then route** stage under the existing source/job authority, using Python [`zipfile.ZipFile.infolist()` / `ZipInfo`](https://docs.python.org/3/library/zipfile.html#zipfile.ZipFile.infolist) for central-directory metadata. Retain and hash the exact outer original first. Treat member names as untrusted labels: reject absolute paths, traversal, alternate separators, duplicates after normalization, encrypted/unsupported compression, nested archives unless explicitly profiled, and special/symlink entries; never extract to a caller-controlled filesystem path. Enforce member count, nesting depth, declared and actual expanded bytes, per-member bytes, total work/time and compression-ratio ceilings. Read a bounded stream per accepted member, hash its actual bytes, then compare declared size/CRC as additional integrity checks. A central-directory entry alone does not prove readable bytes.

Publish an inventory receipt containing outer source ID/revision/SHA, normalized member path and ordinal, size/compression, actual member SHA, parser route/version, companion-group membership, and per-member status (`supported`, `unsupported`, `encrypted`, `corrupt`, `over_limit`, `missing_companion`, `pending`, `failed`). Route PDF/CSV/DOCX/XLSX through existing document readers and GIS/raster/point-cloud members through their canonical authorities, each with its own scope and format-specific completeness rules. In particular, a shapefile's `.shp` without required companion files is incomplete; do not interpret a file extension as a whole dataset. Cite text by outer source plus member fingerprint and native page/row/cell locator. Keep partial results and unresolved members visible rather than publishing a complete-bundle claim. Fence retries with current source/revision and job attempt before derivative publication; private reads repeat access and integrity checks. A member view is a projection of the original, not a new independent source or identity registry. This follows the [adaptive ingestion plan](../../orchestration/ADAPTIVE_INGESTION_EXECUTION.md) while retaining current compatible readers and URLs.

**Verification scope for later implementation:** one real simple archive, one real mixed/incomplete archive and one corrupt/hostile archive under isolation; check exact original download/hash, inventory completeness, per-member citations, denied cross-case read, stale attempt and partial publication.
