## Review conclusions

**Authority and publication.** `DocumentPagesService` requires an exact source UUID, current revision and original SHA256. The initial identity lookup enters `documentSourceTx`: an archived case, absent/mismatched private document receipt, wrong subject, changed byte/hash receipt or nonlatest source cannot become a generic original read. Authority fingerprints cover case/context/access binding and the complete source row. Original bytes are bounded and checked against the retained length/hash; canonical authority is re-resolved after original I/O and after parse/render, with the complete fingerprint compared before returning. The object key is server-resolved and excluded from public projections. Source/job/registry/derivative authority remains read-only.

**Routes and contract.** Both GETs use the existing private guard and private/no-store responses. Mandatory revision/hash, canonical page/range strings, strict query schemas and explicit duplicate-query refusal prevent alternate caller paths, URLs or ambiguous selection. The binary response supplies fixed PNG disposition/type, nosniff, exact source/page/render pins, dimensions and affine headers. Metadata supplies only bounded pagination, source page labels/frames, exact page locators and pinned relative raster URLs. Calibration and anchor regions remain null; unsupported raster pages have null URLs. No OCR region, cadastral measurement or alternate source authority is inferred.

**Frames and raster integrity.** The helper declares the PyMuPDF rectangle convention separately from the displayed top-left point frame. Rotation/origin/size restrictions are checked before rasterization; metadata can remain useful for a page outside that raster profile. The reused renderer opens the exact bytes it hashes, uses an explicit clip and scale, checks pixel/side/PNG limits and returns MuPDF's pixel origin. The service verifies page/source selection, PNG signature/IHDR dimensions and complete PNG hash/length. The mapping is `(local image pixel + pixelOrigin) / scale` in the displayed page frame; PNG DPI is not substituted for this affine or for measurement calibration.

**Native and private-file boundary.** Raw PDF parsing/rasterization occurs in the gated worker, after the reused Windows Job is attached. That Job caps the worker tree's private memory at 2 GiB and kills on close; the supervisor also samples tree RSS, bounds logs and time, stops the owned tree and checks survivors. The outer Node wrapper adds a finite timeout/tree-stop path. Unconfirmed outer cleanup retains the private attempt and blocks later local renders. The private scratch helper resolves the directory outside the repository and restricts its ACL before original bytes are written. Bounded artifact reads precede use; normal/failure cleanup removes the exact owned attempt only.

Concurrency is one operation **per API process**, not a host-global mutex. Thirty seconds is the operation deadline and at most 25 seconds is selected for the native worker, with reserved cleanup time; exceptional cleanup has finite stop/wait grace. Two threads is a compute-environment setting, not a kernel thread ceiling. The memory receipt covers the native worker tree: the reused wrapper imports `fitz`/Pillow dependencies before creating its worker Job, but parses no caller PDF there; it does not cap total API/wrapper RSS. These distinctions must survive later deployment documentation.

**Unsupported and external content.** The helper rejects password/encryption state, oversized page/object counts, unsupported frames and missing selected pages. The external-content guard checks trailer encryption, stream `F`, `Ref/F`, and object-level `S=/JavaScript` entries. URI links and standalone attachment declarations remain inert and are never opened by this flow. PyMuPDF is used to inspect/render, not execute PDF actions. Python socket denial and offline variables are defense in depth, not OS egress enforcement or a comprehensive claim about every PDF action representation. No fresh external-resource or network-isolation qualification follows from this review.
