# AI-04G — source-bound local OCR adapter

30 September 2026. Candidate backend-only adapter, based on lead handoff `a3bc1900dbb22c17497ae500479741508e3e96b2`. The adapter accepts an unchanged original PDF, its expected SHA-256, an explicit page and optional region in that page's displayed top-left point frame. It renders inside the supervised process and emits bounded OCR observations with source-page boxes. It does not enter the shared document source/job authority or change the production `needs_ocr` result. BUNDLE-01 retains those shared seams.

## Contract and limits

[`docling_tesseract.py`](../../../services/geo/geo/usp_document_candidates/docling_tesseract.py) reads at most 16 MiB of source bytes once in the worker, hashes those exact bytes, and parses that same byte array. It supports a PDF of at most eight pages, one selected page per attempt, a zero-rotation displayed page with a zero-based top-left frame and sides at most 2,000 points. Other page frames return `unavailable` with `unsupported_pdf_page_frame`; encrypted or over-page-count inputs are also unsupported. Region coordinates must be finite, within the page and at least one point per side. A render has at most 1.6 million RGB pixels, a 1,400-pixel side and 8 MiB of PNG bytes. No caller-prepared image or source-specific fact is needed.

The source-page box transform records MuPDF's rendered pixel origin and scale, then converts Docling's crop-page points through the PNG's observed DPI. `BOTTOMLEFT` and `TOPLEFT` OCR origins are supported; unknown origins or invalid boxes are withheld with an issue, not placed by guess. Each retained item has exact source SHA, page, displayed-page point box, OCR method and label. At most 64 items, 2,048 UTF-8 bytes per item, 32 KiB of total item text and 128 KiB of result JSON are admitted. Uncitable or over-limit items are omitted with an explicit partial-output issue. `toolStatus` reports Docling completion; `outputStatus` reports missing/truncated cited output; `selection.textCompleteness` remains `unverified` even after tool success. No OCR text is native text or a learning label.

[`run_source_ocr.py`](../../../scripts/usp/document-models/run_source_ocr.py) checks source and pinned local assets before starting the existing gated Windows Job. The worker checks both again, uses the local Heron layout model and Tesseract CLI with English full-page OCR, and disables remote services, plugins, table/picture/formula enrichment and GPU selection. The job has two CPU threads, 6 GiB memory and 600 seconds; Docling's document timeout is 540 seconds. A narrow optional change to [`run_trial.py`](../../../scripts/usp/document-models/run_trial.py) caps the new caller's captured log at 2 MiB without changing old callers. The parent checks `result.json` size before reading or parsing it. Missing model, executable or language data fails locally without fetching. The optional pins are in [`requirements-ocr-docling.txt`](../../../services/geo/requirements-ocr-docling.txt); no package was installed for this increment.
