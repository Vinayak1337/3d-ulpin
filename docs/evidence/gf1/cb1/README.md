# CB1 — retained native records are decoded-values citations

**Result:** both Tweed formats reach included plans, confirmed complete packets,
property cards and consistent verification. Changing only the stored position
refuses with `PACKET_PLAN_NATIVE_KEY_MISMATCH`. Geometry/measurements remain
unavailable; rights remain unassessed. No original, populated volume or demo
service was changed. No provider was called.

## See it

```sh
node docs/evidence/gf1/cb1/run-runtime.mjs <new-receipt.json>
```

The path must be new. The harness fences a nonce-labelled tmpfs PostGIS box,
uses real product functions and current Python readers, and removes its own box.
It needs the retained inputs and existing pinned PostGIS image; it builds nothing.
The `demo` configuration label never points this run at the demo database.

- `result.json`: inputs/hashes, checks, pin audit, design and remaining prerequisites.
- `runtime.json`: concise results; `runtime-verified.json`: actual final receipt,
  33 passed steps, three verified formats and two altered-position refusals.
- `nyc-before-v2.json` / `nyc-after-final.json`: two real NYC records, pre-edit
  fixture versus final code; identical plan/hash, packet, card content and PDF.
- `nyc-postgres-equivalence.ts`: additional same-box proof using original staging
  authority, projection and renderers from `bfc2e45d`, with genuine snapshot and
  issued artifacts. IDs/timestamps are shared and paired PDF entropy is seeded;
  this is not an independently issued pre-edit PostgreSQL card. Owned temporary
  code copies are removed without changing branches or product files.
- `attempts.json`: setup failures, bounded comparisons and the integer-precision
  defect/regression. Historical receipts and before hashes remain untouched.
