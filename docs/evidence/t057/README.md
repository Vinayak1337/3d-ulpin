# Normalized 3D explorer evidence

These are actual application/browser captures and structured results, not image
mockups or a rendered replacement background. The source scene is labelled
synthetic where fictional height/floor detail is used. Source geometry and
analytical quantities remain separate from the display projection.

- `neighbourhood-software.json`: software-WebGL interactions and one deliberate
  refresh-failure injection, with all other errors kept visible.
- `neighbourhood-hardware.json`: the same suite in installed Chrome, including the
  actual reported RTX3070/D3D11 renderer. Not a GPU throughput/capacity benchmark.
- `existing-browser.json`: retained map/session/gesture regression suite.
- `data-preservation.json`: real read-only/HTTP normalization and unchanged table
  fingerprints on the existing PC repository database.
- `garden.png`, `uttam-nagar.png`, `uttam-inspection.png`, `mobile-inspector.png`:
  selected native-Chrome captures. The mobile view is a resized viewport, not a
  tested physical phone.

The T057 result records implementation scope and remaining visual approval. No
source document bytes, credentials, browser cookies or database dumps are stored
in this evidence folder.
