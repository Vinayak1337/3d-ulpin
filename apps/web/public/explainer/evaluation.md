# T061 local model feasibility evidence

These are actual CPU inference receipts on public imagery and published human/vector annotations. They establish a working local proposal path and retain its errors. They do **not** establish cadastral accuracy, Indian pilot acceptance, ownership, legal units, elevations or metric calibration. Published test membership is recorded, but the complete model training history was not independently audited. No paid inference was used.

## Runtime profiles and boundaries

The model manifest pins each source checkpoint, architecture source and derived ONNX hash. The queue binds both the model hash and preprocessing profile; readiness, retry and ingestion reject drift.

- `cubicasa-rooms-768-bilinear-pad64-v1`: upright RGB on white; aspect-preserving maximum edge 768; Pillow bilinear; white right/bottom padding to multiples of 64; RGB/127.5−1; original room head channels 21:33; argmax mask. Original checkpoint and rectangular ONNX parity are retained separately.
- `rfdetr-rgb432-tile512-stride384-threshold050-mask000-v2`: at most 2048 pixels per edge and **4,000,000 total pixels**. Up to 512 pixels per edge follows the original single-tile instance path unchanged. Larger rasters use 512-pixel tiles, stride 384, row-major traversal, final tile anchored to the far edge without padding. Each tile is resized to 432×432 using Pillow bilinear and ImageNet normalization. Foreground masks are unioned at unchanged source pixels, retaining maximum accepted confidence per pixel. Every tile-to-raster transform is retained. Actual positive sample 1200 and empty sample 1 remain exactly equal to their earlier masks and scores.

The tiled union can merge touching roofs and retain edge false positives. The [tiled smoke receipt](tiled-runtime-smoke.json) verifies real inference and coordinate accounting, **not** tiled segmentation accuracy. The processor emits pixel-edge polygons, never bounding-box substitutes. It simplifies by 0.5 pixel, omits components below 16 pixels or above 500 vertices, and returns at most the largest 100 components with omission counts. Original masks remain intact. Confidence is uncalibrated and all candidates require source review. Named-frame calibration and placement evidence are separate requirements before applying metric geometry. No ML output publishes automatically.

Use `python scripts/ml/setup-models.py --source-dir <qualified-artifact-directory>` to verify and install the [pinned artifacts](asset-manifest.json) under `.runtime/ml-models`. No weights or raster originals are committed in this folder. Public receipts use sample IDs and `operator-retained/` paths instead of workstation paths. Floor CPU inference measured 7.24–11.43 seconds in ONNX; runtime building samples measured approximately 2.3–5.25 seconds under shared load. These are observed timings, not latency guarantees.

## Preserved Docker deployment failure

The first actual Linux worker batch failed all three inference items after model execution because the slim container lacked `libexpat.so.1`, required when importing rasterio for polygonization. No spatial facts were applied. The [failure receipt](docker-native-dependency-failure.json) records the affected jobs and diagnosis. The image now installs minimal `libexpat1`; readiness imports native modules instead of only locating package metadata, and dependency failures are classified as `DEPENDENCY_UNAVAILABLE`. A new regression proves this fails before storage/inference. The full same-item retry and recovery outcome belongs to the separate workflow receipt, preserving this failed attempt.
